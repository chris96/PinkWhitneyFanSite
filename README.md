# PinkWhitneyFanSite

A fan site for Pink Whitney with a Fort Lauderdale spring break aesthetic.

I built this for Mikayla Crider and her love for pink whitney

## Stack

- Next.js (App Router)
- TypeScript
- Custom CSS (no Bootstrap)
- Optimized for Vercel deployment

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Content notes

- Source visuals are currently SVG stand-ins under `public/images/source`.
- Additional placeholders are under `public/images/placeholders`.
- Replace those files with your real photos while keeping the same file names for instant updates.
